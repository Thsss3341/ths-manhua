## 安装

1. 在 App 中进入 **设置 → 浏览 → 插件商店**（旧版本中叫「插件仓库 / Extension repos」），点 **添加**，粘贴：

   ```
   https://raw.githubusercontent.com/Thsss3341/ths-manhua/repo/index.pb
   ```

2. 进入 **浏览 → 插件**，安装需要的扩展。本仓库的扩展带有 **THS** 标记。

之后的更新会和其他扩展一样出现在 **浏览 → 插件** 中。

## 扩展

| 扩展 | 网站 | 说明 |
|------|------|------|
| 古古漫画 | http://www.gugu5.cc | 导航站，自动到章节所在的网站读取 |
| 漫画大全 | http://m.yueman1.cc | 与古古漫画同一片库，搜索可用 |
| 嬉皮漫画 | https://m.hipmh.com | 片源多来自官方平台，图片无水印 |

### 古古漫画

一个导航站。不同漫画的章节分别在古古漫画自己的阅读页或合作网站漫画大全上，扩展会自动到对应的网站读取。

部分漫画只链接到腾讯动漫（`ac.qq.com`）等官方网站，这些漫画不显示章节，简介中会注明。

### 漫画大全

与古古漫画共用同一片库。网站自带的搜索无法使用，扩展改为搜索每天更新的全站目录，古古漫画搜不到的漫画可以在这里搜索。在搜索框粘贴漫画大全或古古漫画的漫画链接也可以直接打开。

网站会不时更换域名，最新地址见 http://reman.cc。如果网站搬家，在扩展设置里修改网址即可。

### 嬉皮漫画

片源大多来自快看漫画、腾讯动漫等官方平台，图片没有网站水印。但它**并不比**古古漫画、漫画大全更完整：在已核对的章节中，它使用的是同一套图片，缺图和被截断的页面也一样。可以把它当作更干净的版本，而不是修复缺页章节的办法。

网站的章节列表可能会延迟几个小时更新。扩展会顺着每一话的「下一话」链接查找，所以新章节会在网站列表更新前就出现，这些章节没有上传日期。

### 漫画柜

基于 [Keiyoushi](https://github.com/keiyoushi/extensions-source) 的漫画柜扩展，加入了下文介绍的功能。

它用来替换 Keiyoushi 的漫画柜：**请先卸载 Keiyoushi 版本**，再安装本扩展。书架里的漫画会保留。不要两个同时安装。

设置（浏览 → 插件 → 漫画柜 → ⚙）：

| 设置 | 作用 |
|------|------|
| 章节按上传顺序排列 | 按上传顺序列出章节（默认开启），见[章节排序](#章节排序) |
| 标题语言（方便MAL追踪） | 查找漫画对应的 MyAnimeList 条目，见[MAL追踪](#mal追踪) |
| 显示R18作品 | 显示 R18 作品，更改后需重启 App |
| 主站每十秒连接数限制 / 图片CDN每秒连接数限制 | 请求频率限制，被网站限制访问时可调低 |

## 漫画柜功能

### 章节分区

漫画柜上很多漫画分为单话、单行本、番外篇等分区，每一话的名称下方会显示它所属的分区。

- **只看某个分区：** 在漫画页的筛选菜单里，用 **排除翻译组** 排除其他分区。分区名存放在 App 通常用来记录翻译组的位置。
- **追踪：** 当漫画有单话分区时，单行本和番外篇不会设置话数，「第16卷」不会被当作第16话同步到追踪网站。

### 章节排序

漫画柜只提供最新一话的日期，因此 App 无法按上传日期给其他章节排序。扩展改为把所有分区的章节按上传先后排列，最新上传的在最前。

- **按上传顺序阅读：** 把章节排序设为 **按图源**。
- **像网站一样按分区排列：** 在扩展设置中关闭 **章节按上传顺序排列**，然后下拉刷新漫画。

### MAL追踪

MyAnimeList 搜不到漫画柜的中文标题。在扩展设置中设定 **标题语言（方便MAL追踪）**：

| 选项 | 效果 |
|------|------|
| 中文（漫画柜原标题） | 默认，不做任何改变 |
| 中文，简介里加上MAL ID | 保留中文标题，在简介顶部加上 MAL 标题和 `id:12345` |
| 罗马音（MAL标题） / 英文 | 同时把漫画改名为 MAL 上的罗马音或英文标题，中文标题保留在简介里 |

**追踪漫画：** 打开漫画（或下拉刷新），复制简介中的 `id:12345`，粘贴到 MAL 追踪的搜索框，即可精确找到对应条目。

**如何匹配：** 扩展会在 [Bangumi](https://bgm.tv) 和 [AniList](https://anilist.co) 上查找，用到漫画柜列出的标题、副标题、别名、出品年代和作者。

- **精确匹配：** 标题完全相同。
- **非精确匹配：** 标题只是相近（译名不同），但年代或作者一致。ID 下方会标注 **⚠ 非精确匹配，可能不准确**，且不会改名，追踪前请先确认条目。

**找不到时：** 很多国漫在 MAL 上根本没有条目，这些漫画保留中文标题。AniList 通常收录了它们，App 的 AniList 追踪可直接用中文标题搜到。

**其他说明：**
- 第一次查找每部漫画需要几秒，之后会直接使用缓存。没找到或只有非精确匹配的漫画会在一周后重新查找。
- 已在书架中的漫画，只有在 App 的 **设置 → 高级 → 更新书架中的漫画标题以匹配图源** 开启后才会改名，开启后下拉刷新该漫画即可。

### 导入我的书架

**我的书架** 筛选会列出你在漫画柜收藏的漫画，可以一次性加入书架。以下步骤以 Komikku 为例。

1. **登录：** 在 **浏览** 中打开漫画柜，点 WebView（地球）按钮，在网页上登录账号，然后返回。
2. **新建分类：** 在 **设置 → 书架 → 分类** 中新建一个分类，例如 *manhuagui*。
3. **隐藏已有的漫画：** 开启 **设置 → 浏览 → 隐藏已添加到书架的作品**。
4. **加载我的书架：** 在漫画柜中打开筛选，勾选 **我的书架**，点 **筛选**。
   - 整个书架会一次加载完，约每 20 部 1 秒，请等它加载完成。
   - 只会显示还没加入书架的漫画。
5. **加入书架：** 点 **批量选择模式**（或长按一部漫画），然后 **全选**，再点 **添加到书架**。
   - 如果书架里已有其他网站的同名漫画，Komikku 会询问如何处理重复项，选择 **跳过所有**。
   - 然后选择分类。

如果一次添加太多漫画时卡住，可以分批添加。

## 常见问题

**每次安装或更新扩展都会提示「扫描应用」。**
这是 Google Play 保护机制在检查每个新安装的应用。要避免提示，进入 **设置 → 浏览 → 安装程序**，选择 **Private**，然后卸载并重新安装扩展。之后扩展会保存在 App 内部，Android 不再把它们当作独立应用。

**章节缺图或页面被截断。**
免费来源（古古漫画、漫画大全、嬉皮漫画，以及 mh160 等）大多共用同一套图片，一个来源缺页，通常其他来源也一样。完整版本一般只在官方平台，且往往是付费章节。

**古古漫画搜不到某部漫画。**
改用漫画大全搜索：两者片库相同，漫画大全可以搜索全站。
